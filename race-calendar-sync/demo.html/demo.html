How updates would reach a runner Through a subscribed calendar link, not a one-time download. Each calendar app re-checks the link on its own schedule, and that delay is controlled by the app, so urgent same-day changes still need a direct alert from the organiser. The feed marks each change with SEQUENCE and LAST-MODIFIED so apps can recognise it as a revision of the same entry. Re-importing a downloaded file by hand may create a duplicate instead of updating - the updating route is the subscription.
